# Coffee Price tracker 

Скрипт для получения биржевой цены на кофе Arabica через Yahoo Finance Api.

## Что делает 

- Подключается к финансовому API Yahoo Finance
- Получает текущую цену фьючерса на кофе Arabica (тикер KC=F)
- Выводит цену на консоль

## Структура проекта 

- `coffee_price.py` - основной скрипт
- `exaples/test_payloads.json` - примеры запросов для тестирования 
- `main.py` , `lesson2github.py` - учебные файлы

## Как запустить

1. Активировать виртуальное окружение: source venv/bin/activate
2. Установить зависимости: pip install requests
3. Запустить скрипт: python3 coffee_price.py
